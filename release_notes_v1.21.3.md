### Was ist neu in v1.21.3:

- **Update direkt im Tool repariert:** Auf manchen Macs brach „Jetzt direkt im Tool updaten“ mit einer Zertifikats-Fehlermeldung ab, weil die sichere Verbindung zu GitHub nicht geprüft werden konnte. Das Programm nutzt jetzt die Zertifikate des Systems, damit funktioniert das Update wieder.

**Wichtig:** Wer diese Meldung gesehen hat, installiert v1.21.3 bitte einmal von Hand über den Download-Knopf (macOS: DMG öffnen, App in „Programme“ ziehen; Windows: ZIP entpacken, `PDF_Tool_Windows.bat` doppelklicken). Danach klappen künftige Updates wieder direkt im Tool.
